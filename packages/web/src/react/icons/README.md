# icons

## Overview

SVG glyphs of the built-in controls.

## Components

| Component | Responsibility |
|-----------|----------------|
| [Icon.tsx](Icon.tsx) | Glyph of a built-in control, drawn in the current text color |
| [IconName.ts](IconName.ts) | Glyphs of the built-in controls |
| [IconProps.ts](IconProps.ts) | Props of `Icon` |
| [SkipDirection.ts](SkipDirection.ts) | Direction of a skip button |
| [SkipIcon.tsx](SkipIcon.tsx) | Circular arrow with the skip distance inside it |
| [SkipIconProps.ts](SkipIconProps.ts) | Props of `SkipIcon` |
