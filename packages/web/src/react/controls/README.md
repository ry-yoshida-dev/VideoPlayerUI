# controls

## Overview

Control bar below the video and its controls.

## Components

| Component | Responsibility |
|-----------|----------------|
| [CopyFrameButton.tsx](CopyFrameButton.tsx) | Frame copy button confirming each copy with a short bubble |
| [CopyFrameButtonProps.ts](CopyFrameButtonProps.ts) | Props of `CopyFrameButton` |
| [CopyNotice.ts](CopyNotice.ts) | One showing of the copy confirmation; a new serial restarts it |
| [CopyStatus.ts](CopyStatus.ts) | Outcome of a frame copy |
| [IconButton.tsx](IconButton.tsx) | Round, borderless button holding a single glyph |
| [IconButtonProps.ts](IconButtonProps.ts) | Props of `IconButton` |
| [PlayerControls.tsx](PlayerControls.tsx) | Control bar below the video, laying out every built-in control and the extension slot |
| [PlayerControlsProps.ts](PlayerControlsProps.ts) | Props of `PlayerControls` |
| [SeekBar.tsx](SeekBar.tsx) | Track showing the position in the range; click or drag to seek |
| [SeekBarProps.ts](SeekBarProps.ts) | Props of `SeekBar` |
| [SpeedMenu.tsx](SpeedMenu.tsx) | Chip showing the speed, such as `1×`, opening a list of speeds above it |
| [SpeedMenuProps.ts](SpeedMenuProps.ts) | Props of `SpeedMenu` |
| [TimeIdField.tsx](TimeIdField.tsx) | Shows the time id on screen and jumps to a typed one on Enter |
| [TimeIdFieldProps.ts](TimeIdFieldProps.ts) | Props of `TimeIdField` |
