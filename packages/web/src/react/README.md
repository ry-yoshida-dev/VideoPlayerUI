# react

## Overview

React DOM player and its extension points.

## Components

| Component | Responsibility |
|-----------|----------------|
| [controls](controls) | Control bar below the video and its controls |
| [extensions](extensions) | Components through which children of `VideoPlayer` draw on frames and add controls |
| [hooks](hooks) | React hooks of the player, for applications and extensions |
| [icons](icons) | SVG glyphs of the built-in controls |
| [indicators](indicators) | Transient glyphs and tooltips shown over the player |
| [player](player) | `VideoPlayer`, its props and labels, and the context it offers to extensions |
| [styles](styles) | Style sheet of the player and its injection into the document |
