# src

## Overview

Source of `@video-player-ui/annotations-web`: the `AnnotationLayer` extension of the web player.

## Components

| Component | Responsibility |
|-----------|----------------|
| [AnnotationLayer.tsx](AnnotationLayer.tsx) | Draws annotation layers in step with the frame on screen, with hover highlight, click selection and a show/hide control |
| [AnnotationLayerLabels.ts](AnnotationLayerLabels.ts) | Tooltips of the annotation toggle; replace them to translate |
| [AnnotationLayerProps.ts](AnnotationLayerProps.ts) | Props of `AnnotationLayer` |
| [defaultAnnotationLayerLabels.ts](defaultAnnotationLayerLabels.ts) | English tooltips used when an application supplies none |
